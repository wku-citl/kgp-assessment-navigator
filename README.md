# Essential Skills Assessment Navigator

A guided tool to help faculty identify meaningful, well-aligned assessments for the Kentucky Graduate Profile's 10 Essential Skills.

## What it does

Faculty work through a short reflective process: select the Essential Skill their course addresses, the level at which the course addresses it (introduced, reinforced, or mastered, based on their program's curriculum map), and what their learning outcomes ask students to do.

The tool then provides:

- Where the course falls in the CPE performance progression, with the Benchmark, Milestone, or Capstone indicators that apply
- A note on whether the course's stated level and its learning outcomes appear to line up
- Four assessment approaches suited to that skill and level, each with guidance on adapting it to a specific discipline
- Common pitfalls worth checking for

There is also an option to select a second Essential Skill, since many courses address more than one.

## What it doesn't do

The suggestions are a starting point for faculty judgment, not a determination about any course. Faculty know their students and their discipline; the tool is meant to prompt reflection and offer options, not prescribe an answer.

## Privacy

Everything runs in the browser. Nothing is transmitted, collected, or stored anywhere. No account, no login, no data leaves the page.

## Using it

Open the page and work through the steps. Nothing to install.

To host your own copy, download `index.html` and put it wherever you host web pages. It's a single file with no dependencies.
